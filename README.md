# Mama Pili’s Kitchen: Menu and Ordering

A responsive restaurant menu with a cart, pickup or delivery choice, and
ordering through WhatsApp.

**Live site:** https://your-username.github.io/restaurant-menu/

## Features
- Menu with photos and section filters
- Cart with quantity buttons that is kept if the page is refreshed
- Pickup or delivery, with delivery fee and address
- Special instructions field
- Open now / Closed badge
- Order sent as a WhatsApp message
- About and Contact pages, responsive on phones

## Built with
HTML, CSS, JavaScript (no frameworks), deployed on GitHub Pages.

## What I learned
I created this website for local hotels with no website, this is good for marketing online. It was really not that hard but I am still working on adding new tracking order features.
